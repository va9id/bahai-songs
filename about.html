About

Purpose

Ever been in a devotional and everyone starts singing and you don't know the lyrics, we sure do, it's the worst. So we built this simple website where you can quickly pull up the lyrics to a song. This website is nothing fancy and just shows lyrics to different Bahá'í songs. If you're looking for guitar chords for the songs, checkout bahaisongproject.com, which is another great individual Bahá'í songs initiative.

Contributing (for the 🤓)

The source code for this website is open-source and available on Github, feel free to contribute.

Legal

Notice

Please note that is an individual initiative and is not affiliated with the official Bahá'í website whatsoever. Please visit bahai.org for more information about the Bahá'í Faith.

Accuracy

We try our best to ensure all the song lyrics are correct and we carefully review the lyrics of each submitted song. Nonetheless, it's still possible that the lyrics are not completely accurate. If you feel that's the case, do not hesitate to report it.

Copyright ©

The songs available on the site do not belong to bahaisongs.ca, rather they belong to their respective copyright holders. If you're a copyright holder and want your song taken down, please reach out.
